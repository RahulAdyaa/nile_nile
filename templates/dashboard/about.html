About Nile Analytics

E-commerce analytics platform built for data-driven decisions.

What is Nile Analytics?

Nile Analytics is a full-stack data analytics platform designed for e-commerce businesses. Upload your sales data in any format — CSV or Excel — and get instant insights into revenue, profit margins, customer demographics, product performance, and regional trends. The platform automatically cleans, transforms, and loads your data using a sophisticated ETL pipeline.

Architecture

Backend

Django + PostgreSQL

Task Queue

Celery + SQLAlchemy Broker

ETL Engine

Pandas + NumPy

Forecasting

Holt-Winters (statsmodels)

Charts

Plotly.js (Interactive)

AI Analytics

Groq API + Llama 3.3 70B

Authentication

Django Allauth + OAuth 2.0

API Layer

DRF + SimpleJWT

Frontend

Django Templates + HTMX

Styling

TailwindCSS

Animations

GSAP + Locomotive Scroll

Anomaly Detection

SciPy (Z-Score Analysis)

Excel Export

openpyxl (Charts + Data)

Production

Gunicorn + WhiteNoise

Key Features

  • ● Multi-file upload with automatic column detection and smart merging
  • ● Star schema data model (Customer/Product dimensions → Sale fact table)
  • ● Background processing via Celery with automated cron jobs
  • ● 90-day revenue forecasting with confidence intervals
  • ● Ask Your Data — Groq-powered (Llama 3.3 70B) natural language queries over your sales dataset
  • ● What If simulator — real-time scenario modelling for price, discount, and volume levers
  • ● Role-based access control with JWT API authentication
  • ● Full audit logging for security telemetry
